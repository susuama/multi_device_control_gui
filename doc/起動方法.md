# 導入・起動方法

## 1. 必要な環境

- Windows（64-bit）
- Python 3.13（64-bit）
- Node.js 24 LTS / npm
- Microsoft Edge WebView2 Runtime（pywebviewで画面を表示する場合）

2026-10-17にPython 3.13.6、Node.js 24.18.0、npm 11.16.0で依存関係の導入・APIテスト・ビルドを確認。
実機用SDKの導入と、実機を使った取得・記録は本プロジェクトでは未確認。

以下のコマンドはPowerShellで実行する。最初はプロジェクトのルートフォルダを開く。

## 2. Python環境の準備

仮想環境を作成し、必要なライブラリをインストール。

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade "pip>=26.2.0"
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

既存の仮想環境を使う場合は、最初の作成コマンドは不要。他のプロジェクトのライブラリと依存が衝突する場合は、新しい仮想環境を使用する。

## 3. フロントエンドの準備

```powershell
cd frontend
npm ci
```

## 4. 通常画面の起動

### フロントエンド

`frontend` フォルダで以下を実行。

```powershell
npm run dev
```

### デスクトップアプリ

別のPowerShellを開き、プロジェクトのルートフォルダで以下を実行。

```powershell
.\.venv\Scripts\python.exe run.py
```

APIサーバーは `127.0.0.1:8000`、画面は `127.0.0.1:5173` を使用。
現在の通常画面はAPI通信テスト用。デバイススキャンでダミーのパワーメーター2台を確認できる。
画面を閉じるとAPIサーバーの終了を待つ。フロントエンドは起動したPowerShellでCtrl+Cを押して停止。

### ブラウザーでAPI通信だけを確認する場合

デスクトップアプリの代わりに、ルートフォルダで以下を実行。

```powershell
.\.venv\Scripts\python.exe -m uvicorn backend.app.main:app --host 127.0.0.1 --port 8000
```

フロントエンドも起動し、ブラウザーで [通常画面](http://127.0.0.1:5173/) を開く。
この起動方法ではWindowManagerがないため、ウィンドウ操作APIは503を返す。APIサーバーもCtrl+Cで停止。

## 5. デザインデモ

`frontend` フォルダで以下を実行。

```powershell
.\start-design-demo.cmd
```

[デザインデモ](http://127.0.0.1:5175/design-demo.html) をブラウザーで開く。バックエンドは不要。
データ・画像・接続状態・取得・記録は見本で、再読み込みすると初期状態に戻る。停止はCtrl+C。

## 6. テスト・ビルド

ルートフォルダでテスト用の依存関係を追加し、回帰テストを実行。

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -B -m unittest backend.tests.test_device_disconnect -v
```

テストはダミー機器を使用。実機やデスクトップ画面は起動しない。
`python -B -m unittest discover -s backend/tests -v` でも同じ回帰テストを探索できる。

フロントエンドは `frontend` フォルダで以下を実行。

```powershell
npm run lint
npm run build
npx --no-install vite build --config vite.demo.config.ts
npm audit
```
