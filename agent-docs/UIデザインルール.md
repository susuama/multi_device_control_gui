# UIデザインルール：採用版A2

採用日：2026-10-15。研究用ソフトウェアの外観はA2を基準とする。装飾を増やさず、情報密度・整列・状態の読み取りやすさを優先する。

この文書は外観の最小仕様、参照デモのCSSは部品ごとの詳細の基準とする。機能構成と実装順序は[フロントエンドUI設計・実装計画.md](<フロントエンドUI設計・実装計画.md>)を参照する。

## 1. 参照デモ

- 入口：[A2参照デモ](http://127.0.0.1:5175/design-demo.html)。起動は `frontend/start-design-demo.cmd`、停止は起動したターミナルでCtrl+C。
- 実装：`frontend/src/design-demo/DesignDemo.tsx`、配色・寸法：`frontend/src/design-demo/design-demo.css`。
- A2のみを表示する。上端の「参照デモ／表示状態／見本データ」は確認用の操作であり、製品UIには含めない。
- 設定ビューの「配色」でダーク／ライトを選び、「設定を適用」で全パネルへ反映する。「元に戻す」は未適用の変更を取り消す。
- デバイス管理、個別デバイス、測定・記録、テーブル、グラフ、イメージ、設定の7ビューと、測定・カメラ・1パネルの配置を確認できる。
- データ・画像・取得・記録は見本。実機通信、ファイル保存、別ウィンドウ間の同期は行わない。起動時設定・保存先・ウィンドウサイズも見本値。再読み込みで初期状態へ戻る。
- 現行画面例：[ダーク](../design-demo/screenshots/A2-dark.jpg)、[ライト](../design-demo/screenshots/A2-light.jpg)。

## 2. 寸法と文字

製品画面は Astryx 0.7.11 の Neutral を継承した共通テーマを使用する。参照デモは採用時の見本として残し、現在の配色・寸法の定義は `frontend/src/theme/measurementTheme.ts` と `frontend/src/theme/density.css` を正とする。

| 項目 | コンパクト | 標準（既定） | ゆったり |
|---|---:|---:|---:|
| 本文・単位 | 11px | 12px | 14px |
| 補助文字 | 10px | 11px | 12px |
| 強調文字（太さ600） | 12px | 14px | 16px |
| 入力欄・操作ボタン | 22px | 26px | 32px |
| パネルヘッダー・設定行 | 28px | 32px | 38px |
| 基本余白単位 | 3px | 4px | 6px |
| 内容の左右余白・セクション内余白 | 6px | 8px | 12px |

- 密度はアプリ全体に適用し、ビューごとに別の値を持たせない。`AppTheme` の `density` に `compact` / `standard` / `comfortable` を指定する。選択UI・保存処理は今後追加する。
- 本文は `Segoe UI, Yu Gothic UI, Meiryo, sans-serif`。数値・時刻・識別値は `Cascadia Mono, Consolas, monospace`。Webフォントへの通信は不要。
- パネル名・小見出し・表見出しは原則400の重み。モデル名などの強調は共通の強調トークンを使う。
- パネルフッターは設けない。パネル間の隙間・境界の操作範囲、アイコン、グラフ・画像の倍率は密度に連動させない。
- パネルの角丸6px、操作部品・セクションの角丸4pxを維持する。接続・切断ボタンは左右が半円の形を使う。
- 設定は左にラベル、右に入力欄を整列し、単位を入力欄の右に置く。設定セクションは左揃え・最大幅640px。
- 配色変更後と Astryx 更新後は `frontend` で `npm run theme:build` を実行する。生成物は直接編集しない。密度CSSの変更では再生成不要。

同じ色を使う部品は共通パレットを参照する。特定の部品だけを明るくせず、色の値を編集して共有先へ反映する。

製品画面では、色と用途の対応を次の変数で共有する。ダーク／ライトの切り替え時には各色の値も切り替わる。状態は色だけに頼らず、文字でも示す。

| 用途 | 役割別変数 | 色の変数 | ダーク | ライト |
|---|---|---|---|---|
| 選択・主要操作 | `--accent` | `--blue` | `#4772b3` | `#4772b3` |
| エラー・失敗 | `--error` | `--red` | `#ed9993` | `#a53832` |
| 接続済み・成功 | `--success` | `--green` | `#91bb9b` | `#28663b` |
| 注意・確認が必要な状態 | `--warning` | `--yellow` | `#e5c16d` | `#806000` |

フォーカス表示は青系の `--focus` を使う。グラフの系列色は識別用であり、この状態色の意味とは別に扱う。

製品画面で名前などを強調する場合は、`--text-emphasis`（ダーク `#ffffff`、ライト `#171717`）、`--font-size-emphasis`（密度に応じて12／14／16px）、`--font-weight-emphasis`（600）を使う。状態を示す文字は、意味に対応する状態色を使う。

| ライトの共通パレット | 値 | 主な共有先 |
|---|---|---|
| `--gray-200` | `#eeeeee` | パネルヘッダー、ウィンドウ下部バー |
| `--gray-250` | `#ececec` | 通常ボタン、参照デモの上端バー、表の下罫線 |
| `--gray-300` | `#e8e8e8` | ウィンドウ上部バー、ボタンのホバー背景、画像周囲 |
| `--gray-400` | `#dadada` | ウィンドウ背景、ツールバー・セクション・デバイス行の境界 |

`--frame`・`--header`・`--control`などの役割別変数からパレットを参照する。画像の画素・画像上の注釈にはテーマを適用しない。部品固有のホバー・フォーカス・罫線の詳細はCSSを参照する。

## 4. 配置とパネル

- 最小構成は1パネル。全ビューで同じパネル枠を使う。レイアウトはパネルの位置・分割・大きさだけを扱う。
- パネルヘッダーは左から、ビュー切り替え、ビュー名、パネル番号、最大化、閉じる。最後の1パネルは閉じられない。
- ウィンドウヘッダーは左にアプリ名、右に「測定・カメラ・1パネル → パネル追加 → 配置初期化」。レイアウトボタン間の隙間は0px、左右余白は8px。
- パネルはヘッダーと伸縮する本文で構成する。内容はビュー内でスクロールする。
- 高さ50pxではヘッダーだけを表示し、本文を非表示・操作不可にする。再拡大時に編集中の値を戻す。最小高さは入れ子の分割にも反映する。
- 設定は機器情報・測定設定・記録出力などのまとまりで区切る。個別デバイスの適用・元に戻すは本文スクロールの外に置く。
- 設定ビューはアプリ共通と対象ウィンドウの設定を分け、機器選択を置かない。適用済み値を共有し、未適用入力はパネルごとに保持する。
- 狭いツールバーは横スクロールし、長い名前は省略表示する。ビュー切り替えは残す。650px以下では補助表示を減らし、1パネル構成を使えるようにする。

## 5. データと状態表示

- 表は見出しを固定し、数値を右揃えにする。単位は見出しに示し、行を薄い罫線と交互背景で区別する。
- グラフは凡例・軸・単位・表示範囲を示す。パネルのサイズ変更で文字を縦横に伸縮させない。
- 画像はアスペクト比を維持し、拡大時は内容領域をスクロールする。
- 状態は色と「接続済み」「取得中」「記録中」などの文字で示す。選択行の文字は白。フォーカスは2pxのアウトライン（ダーク `#8fbeef`、ライト `#4772b3`）。
- 未接続・データなしは次の操作を短く示す。エラーは理由と確認先を表示する。操作不可の項目は無効化する。
- 見本の機器名・入力範囲・保存先を全機器の仕様に固定しない。機器固有の項目は個別デバイス内で共通部品を使って表示する。

## 6. 変更時の確認

ダーク／ライト、7ビュー、正常／未接続／データなし／保存エラー、狭いパネルと最小高さを確認する。型チェック・デモ部分のlint・デモ用ビルドを実行する。採用した色や寸法を変更したら、この文書と参照デモを同時に更新する。

調査根拠・旧比較案・過去の検証記録は[履歴](../design-demo/archive/README.md)に保管する。実装時の基準は本書と現行A2デモとする。
